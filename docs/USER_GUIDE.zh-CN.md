# TZswitch 使用说明

TZswitch 提供两个独立功能：**切换系统时区**，以及**在菜单栏显示备用时区的星期和时间**。最多保存 3 个常用城市，一个即可使用。

[项目首页](https://github.com/jockerxb/TZswitch) · [下载最新版](https://github.com/jockerxb/TZswitch/releases/latest) · [反馈问题](https://github.com/jockerxb/TZswitch/issues)

## 应用场景

配合 VPN 使用时，如果工作环境或软件流程要求系统时区与 VPN 地区一致，可以用常用城市手动切换；再把本地城市设置为备用时区，切换后仍能查看本地时间。出差、旅行和跨地区工作时，也可以让系统使用目的地时间、菜单栏保留家乡时间。

本工具不检测或控制 VPN，不改变 IP 地址或实际位置；仅切换时区不能保证其他软件的行为。

## 1. 下载与安装

### 安装要求与权限

| 项目 | 要求 |
| --- | --- |
| macOS | **13.0 及以上** |
| Mac 芯片 | Apple Silicon（M 系列）和 Intel，同一个通用安装包 |
| 额外软件 | 使用 Release 安装包不需要安装 Xcode、Python 或其他运行依赖 |
| 首次打开 | 当前版本尚未公证；若被系统拦截，按下方“仍要打开”步骤处理 |
| 切换时区 | 需要 macOS 管理员授权，系统弹窗可能显示 `osascript` |

目前已在 **macOS 15.5** 上完成实际启动和管理员授权切换验证；支持范围内的其他系统版本尚未逐一实机测试。

管理员密码仅在 macOS 系统弹窗中输入，App 不保存密码。普通账号需要可用的管理员凭据才能批准切换。**不需要辅助功能、屏幕录制、完全磁盘访问、定位、相机或麦克风权限。** 常用城市只保存在本机。

### 安装步骤

1. 打开[下载页面](https://github.com/jockerxb/TZswitch/releases/latest)，在 Assets 中下载名称以 `-macOS-universal.zip` 结尾的安装包。
2. 解压，将 **TZswitch.app** 拖入“应用程序”。使用 App 不需要安装 Xcode 或运行源码。
3. 从“应用程序”或 Spotlight 搜索 TZswitch 并打开。

### 首次打开提示“Apple 无法验证 TZswitch”

当前安装包使用 ad hoc 签名，尚未经过 Developer ID 签名与 Apple 公证，因此下载后可能出现“未打开 TZswitch，Apple 无法验证……”的提示。

<img src="images/macos-unverified-app.png" width="420" alt="macOS 提示未打开 TZswitch，Apple 无法验证 App">

确认安装包来自[本仓库 Releases](https://github.com/jockerxb/TZswitch/releases/latest) 后，按以下步骤打开：

1. 在拦截弹窗中点击 **“完成”**。
2. 打开 **系统设置 → 隐私与安全性**，向下找到 TZswitch 被阻止的提示。
3. 点击 **“仍要打开”**，按系统提示授权，再点击 **“打开”**。

系统会记住对该 App 的允许，之后可以正常启动。操作依据见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

## 2. 首次设置

1. 点击绿色入口 **“点击设置常用城市”**。
2. 搜索城市或时区，点击需要的城市。
3. App 自动关闭选择面板并请求 macOS 管理员授权。在系统弹窗中输入本机管理员密码并确认。
4. 验证切换成功后，App 显示新的系统时区，并保存这个常用城市。

**设置一个城市就完成了。** 需要第 2、第 3 个城市时，点击 **“添加常用时区”** 逐个添加，最多 3 个。没有预设城市，常用城市不能重复；原版本保存的城市会在升级后保留。

如果所选时区已经生效且自动时区已关闭，App 会直接保存，无需重复授权。

## 3. 查找城市和时区

搜索支持中文城市名、英文城市名、IANA 标识和 UTC 偏移，不区分英文大小写。

| 输入示例 | 查找内容 |
| --- | --- |
| `北京`、`Beijing`、`北京时间` | 北京 / 上海，使用 `Asia/Shanghai` |
| `纽约`、`New York` | 纽约，使用 `America/New_York` |
| `Asia/Tokyo` | 东京 |
| `utc9`、`utc 9`、`UTC+9` | 当前为 UTC+09:00 的城市 |
| `utc-8` | 当前为 UTC−08:00 的城市 |
| `utc5:30`、`utc5.5` | 当前为 UTC+05:30 的城市 |
| `utc5:45`、`utc5.75` | 当前为 UTC+05:45 的城市 |

还可以组合搜索，例如 `utc8 北京`。

列表按**当前 UTC 偏移从小到大**分组。右侧 UTC 导航可独立滚动，点击偏移即可跳到相应分组；城市列表滚动时，当前分组标题会固定在顶部。

“X 个时区 · Y 个城市”分别表示搜索结果中的 UTC 偏移分组数和城市条目数。夏令时会影响当前偏移，因此分组数和 UTC 搜索结果可能随日期变化。

列表采用系统时区的代表城市，不是全球所有城市名录。找不到某个城市时，可尝试英文名称或所在地的 UTC 偏移。同城且完整规则一致的兼容名称会合并展示，旧 IANA 名称仍可搜索。

## 4. 日常操作

| 位置 | 操作 |
| --- | --- |
| 常用城市卡片主体，包括名称和时间 | 点击后切换到该城市的系统时区，按提示完成授权 |
| 卡片右侧 `>` | 更换该位置的常用城市；选中新城市后会请求授权并切换 |
| “添加常用时区” | 按需添加第 2、第 3 个常用城市；最多 3 个 |
| 绿色边框 | 表示系统当前正在使用该城市的时区 |
| 顶部“系统当前时区”卡片 | 显示系统实际使用的城市、UTC 偏移、时间和日期 |
| 标题右侧 GitHub | 在默认浏览器打开项目首页，查看源码、下载更新或反馈问题 |

若系统使用的时区不在常用城市中，顶部仍显示系统真实状态，常用城市卡片不会误标为当前时区。

## 5. 备用时区显示

1. 打开主界面的 **“备用时区显示”** 开关。
2. 手动选择要保留查看的城市，例如你的本地城市；不会默认采用系统时区或任一常用城市。
3. 选好后开关才会开启，macOS 顶部菜单栏显示 **“周日 18:22”** 这样的星期和时分。取消选择则保持关闭；再次开启也先让你手动选择。
4. 更换备用城市可点击主界面的备用城市，或点击菜单栏时间后选择 **“更换备用时区…”**。

**调整菜单栏位置**：按住 **Command（⌘）**，再用鼠标拖动顶部备用时间，松开即可放到“控制中心”图标左侧等位置。这是 [macOS 原生的菜单栏排序操作](https://support.apple.com/guide/mac-help/whats-in-the-menu-bar-mchlp1446/mac)，普通拖动不会移动。位置由 macOS 管理；切换开关时复用同一菜单栏项目。

备用时区只用于显示，不切换系统时区，不请求管理员授权，也不占常用城市名额。它可以与常用城市相同或不同，按该城市的实际规则自动计算夏令时和跨日。关闭备用显示时不需要选择城市。

## 6. 取消授权与退出

- 在城市列表点击 **“× 关闭”**或按 **Esc**：返回主界面，不修改城市和系统时区。
- 在 macOS 授权弹窗点击**“取消”**，或切换失败：保留之前的常用城市；首次设置时，该位置仍为空。只有验证成功才保存新城市。
- **备用时钟关闭**：关闭主窗口或退出 App 后，进程结束，**已生效的系统时区继续保留**。
- **备用时钟开启**：关闭主窗口或退出主界面（含 Command-Q）后，系统时区和菜单栏备用时间都保留；主窗口与 Dock 图标隐藏，时钟继续运行。
- 点击菜单栏备用时间，选择 **“退出××时间”**：只停止备用时钟，**不会恢复或改变系统时区**。如果主窗口已隐藏，进程也随之结束；如果主窗口仍打开，可继续使用常用时区切换。
- 系统授权期间需先完成或取消授权，再退出主界面。

再次打开 App 时会读取系统实际时区，不会自动切换。常用城市保存在本机，无需重复设置。

没有独立后台服务，也没有自动开机启动。电脑注销、重启或关机时进程会结束；之后重新打开 App，恢复之前保存的设置。

## 7. 常见问题

**为什么弹窗里显示 osascript？**

TZswitch 通过 macOS 自带的授权机制修改系统时区，系统弹窗可能显示“osascript 想要进行更改”。密码仅在 macOS 系统弹窗中输入，App 不保存管理员密码。

**退出后为什么时区没有恢复？**

这是预期行为。TZswitch 修改的是系统设置，退出 App 后继续生效。切换时会关闭根据位置自动选择时区，避免 macOS 自动改回；网络时间自动校准不受影响。如需恢复自动时区，请在 macOS 的日期与时间设置中重新开启。

**为什么搜索 utc-8 没有洛杉矶？**

UTC 搜索按当前日期的实际偏移匹配。洛杉矶在夏令时期间为 UTC−07:00，可搜索 `utc-7`，或直接搜索“洛杉矶”。

**为什么菜单栏没有备用时间？**

该功能默认关闭。请打开“备用时区显示”并手动选择城市；如果取消选择，开关仍保持关闭。选择城市后才会显示时间，主界面关闭后仍保留。
